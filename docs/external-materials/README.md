# Внешние материалы

Папка `docs/external-materials/` предназначена для хранения сторонних, неподтверждённых или частично релевантных материалов, которые **не входят в основную линию методических PDF проекта**.

## Назначение

Здесь размещаются:

- документы, найденные вне основной методички ПЗ-1..ПЗ-N;
- материалы с неясным происхождением;
- файлы, которые потенциально полезны, но не подтверждены как canonical source;
- альтернативные или параллельные учебные материалы.

## Статус материалов

Все файлы в этой папке считаются:

- **non-authoritative** (не являются источником истины);
- **не проверенными на соответствие основной методичке**;
- **необязательными для реализации функционала проекта**.

Использование таких материалов требует явного решения и дополнительной валидации.

## Ограничения на использование

Материалы из `docs/external-materials/`:

- не должны использоваться для обновления:
  - `docs/methodics-mapping.md`
  - `docs/cipher-coverage-matrix.md`
- не должны влиять на:
  - архитектурные решения;
  - контракт данных;
  - тестовые векторы;
- не должны автоматически приводить к реализации новых шифров или изменению существующих.

Любое использование должно быть:

- явно зафиксировано;
- обосновано;
- отделено от основной линии методички.

## Связь с основной методичкой

В проекте существует основная линия материалов:

- `docs/pdf/` — локальные PDF-файлы методички (source of truth) :contentReference[oaicite:0]{index=0}

В отличие от неё:

- `docs/external-materials/` — это **вспомогательный буфер**, а не часть методической базы.

## Рекомендации по работе

Если найден новый материал:

1. Сначала поместить его в `docs/external-materials/`;
2. Не использовать сразу в коде или данных;
3. Провести проверку:
   - совпадает ли с текущей методичкой;
   - не противоречит ли уже реализованным алгоритмам;
4. Только после этого принимать решение:
   - либо перенести в основную методичку (`docs/pdf/`);
   - либо оставить как внешний источник;
   - либо полностью игнорировать.

## Причина существования папки

Практика показала, что в открытом доступе встречаются материалы:

- с похожими названиями ПЗ;
- с частичным пересечением тем;
- но из **других методических линий**.

Без явного разделения это приводит к:

- смешению источников;
- некорректной реализации алгоритмов;
- появлению несогласованных тестовых векторов.

Эта папка нужна, чтобы этого избежать.
