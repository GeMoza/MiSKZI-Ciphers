## Фиксация дефектов

### UI-PZ4-PZ5-001

**Шифр:** `richelieu`
**Область:** Variants / data quality
**Серьёзность:** medium
**Статус:** open

**Симптомы:** часть вариантов не выполняется из-за несоответствия длины текста и суммы размеров блоков.

**Шаги воспроизведения:**

1. Открыть Playground для `richelieu`.
2. Последовательно выбрать варианты 1, 3, 4, 5, 8.
3. Запустить шифрование или расшифрование.

**Фактический результат:**
Возникают ошибки:

* variant 1: `richelieu: text length (12) must equal sum of block sizes (11)`
* variant 3: `richelieu: text length (19) must equal sum of block sizes (16)`
* variant 4: `richelieu: text length (18) must equal sum of block sizes (16)`
* variant 5: `richelieu: text length (19) must equal sum of block sizes (16)`
* variant 8: `richelieu: text length (33) must equal sum of block sizes (32)`

**Ожидаемый результат:**
Методические варианты должны выполняться без ошибок формата данных.

**Предварительный диагноз:**
Алгоритм, вероятно, работает корректно; проблема похожа на ошибочно занесённые варианты в `variants.json`.

**Предполагаемый слой проблемы:** `data`
