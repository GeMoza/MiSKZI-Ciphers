# Локализация

## Где находится логика

Локализация UI сосредоточена в `src/miskzi_ciphers/ui/i18n.py`.

Главные словари:

- `UI_STRINGS` — общие UI-строки;
- `CIPHER_LABELS` — отображаемые названия шифров;
- `FAMILY_LABELS` — подписи семейств;
- `PARAM_LABELS` — подписи параметров ключа;
- `PARAM_HELPS` — help-тексты для параметров;
- `PARAM_VALUE_LABELS` — подписи значений enum-параметров;
- `DESC_OVERRIDES` — текстовые override-описания для конкретных шифров.

Функции-обёртки:

- `t()`
- `label_cipher()`
- `label_family()`
- `label_param()`
- `label_param_help()`
- `label_param_value()`
- `description_override()`

## Что локализуется

Сейчас локализуются:

- названия страниц UI;
- подписи кнопок и сообщений;
- названия шифров;
- названия семейств;
- названия параметров;
- help-тексты параметров;
- подписи значений для некоторых enum-полей.

Фактический активный язык сейчас — `ru`: `get_lang()` всегда возвращает `LANG_RU`.

## Что не локализуется

Не всё в проекте переводится автоматически:

- системные `cipher_id` и имена полей ключа;
- сообщения об ошибках, которые приходят из самих шифров;
- содержимое `describe().notes`, если для него не задан override;
- данные из `variants.json`.

Из этого следует важное правило: локализация UI не заменяет аккуратные технические тексты внутри шифров.

## Внутренние имена против отображаемых подписей

Нужно различать два слоя:

- внутренние имена параметров: `k`, `matrix`, `group_size`, `keyword`;
- UI-подписи: `Сдвиг`, `Матрица ключа`, `Размер группы`, `Ключевое слово`.

UI строится по внутренним именам, а `i18n.py` только переводит их в человекочитаемые подписи. Менять внутренние имена ради красоты нельзя: это сломает `parse_key()`, данные и тесты.

## Как добавлять подписи для нового шифра

При добавлении нового `cipher_id` обычно нужно обновить:

1. `CIPHER_LABELS["ru"][cipher_id]`
2. при необходимости `DESC_OVERRIDES["ru"][cipher_id]`
3. `FAMILY_LABELS`, если появляется новое семейство

Если этого не сделать, UI покажет сырой `cipher_id`.

## Как добавлять подписи для новых параметров

Для параметра `<cipher_id>.<param_name>` обычно добавляются:

- `PARAM_LABELS["ru"][f"{cipher_id}.{param_name}"]`
- `PARAM_HELPS["ru"][f"{cipher_id}.{param_name}"]` при необходимости
- `PARAM_VALUE_LABELS["ru"][f"{cipher_id}.{param_name}"]` для enum-значений

Это не влияет на криптологическую логику, но сильно улучшает читаемость формы и тестируемость UI-слоя.

## Ограничения текущей модели

- мультиязычность пока инфраструктурно намечена, но по факту UI работает в одном языке;
- локализация не покрывает все возможные тексты из `describe()`;
- если в `describe()` уже лежит повреждённый или нечитабельный текст, UI не исправит его автоматически.
