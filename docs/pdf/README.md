# PDF-материалы

Папка `docs/pdf/` предназначена для локальных PDF-методичек и других справочных материалов по практическим занятиям.

Правила:

- PDF можно хранить здесь локально для работы над проектом;
- сами PDF-файлы не должны попадать в git;
- файл `README.md` в этой папке остаётся в репозитории, чтобы структура каталога была зафиксирована документацией.
