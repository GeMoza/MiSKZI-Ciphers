# Changelog

## Текущее состояние

Ветка `0.9.2` описывает учебный проект с единым контрактом шифров, Streamlit UI, `variants.json` как основным форматом учебных данных и комплектом документации в `docs/`.

## Недавние изменения

### UI и локализация

- В UI выделены две основные страницы: Playground и Data Manager.
- Подписи интерфейса и параметров вынесены в `ui/i18n.py`.

### Формат данных

- Основным источником данных стал `data/<cipher>/variants.json`.
- В корне `variants.json` закреплён раздел `meta`.
- Для legacy-проектов сохранена миграция из `free_text.txt` в `meta.free_text`.

### Реализованные шифры

- В проекте собран набор шифров из нескольких практических блоков.
- В текущем состоянии присутствует и более позднее добавление `ramsey`, которое уже имеет данные и отдельные тесты.

### Документация

- Добавлен каталог `docs/` с архитектурной и практической документацией.
- Корневой `README.md` сокращён до роли "быстрого входа" и отсылает к подробностям в `docs/`.

## О версиях

Точная древняя история версий в репозитории не зафиксирована в одном источнике, поэтому здесь сознательно описаны только актуальное состояние и ближайшие заметные изменения без реконструкции неподтверждённой хронологии.
