# Changelog

## Текущее состояние

Текущая версия проекта в `pyproject.toml` — `0.10.0`.
Проект описывает учебный набор классических и учебно-методических шифров с единым контрактом, Streamlit UI, `variants.json` как основным форматом учебных данных и комплектом документации в `docs/`.

## Недавние изменения

### UI и локализация

- В UI выделены две основные страницы: Playground и Data Manager.
- Подписи интерфейса и параметров вынесены в `ui/i18n.py`.

### Формат данных

- Основным источником данных стал `data/<cipher>/variants.json`.
- В корне `variants.json` закреплён раздел `meta`.
- Для legacy-проектов сохранена миграция из `free_text.txt` в `meta.free_text`.

### Реализованные шифры

- В проекте собран набор шифров из нескольких практических блоков.
- Для `hill` уточнен методический инвариант: шифр работает только на `RU_33` с `Ё`, использует 1-based нумерацию букв по модулю 33 и теперь явно отклоняет `?`, пробелы и другие посторонние символы как некорректный ввод.
- Для `ramsey` зафиксирована методическая версия ПЗ-05 с таблицами `SUBWAY` / `ASINTOER`, смешанными кодами `0..7` и `80..99` и контрольным примером `PRACTICE MAKES PERFECT`.
- Для `rubik_2x2` добавлена учебная развёртка 2x2 по ПЗ-05 с контрольным примером `РТУ МИРЭА -> ТМРРИАЭУ`.

### Документация

- Добавлен каталог `docs/` с архитектурной и практической документацией.
- Корневой `README.md` сокращён до роли "быстрого входа" и отсылает к подробностям в `docs/`.
- Проведён аудит документации против фактического состояния `src/`, `data/`, `tests/` и локальных PDF-методичек.
- В `docs/methodics-mapping.md` зафиксированы текущие расхождения, включая отсутствие `data/` для `bacon`, пограничный статус `vigenere` между ПЗ-02 и ПЗ-03 и наличие новых тем в ПЗ-06 и ПЗ-07.
- В `docs/README.md` добавлен рабочий чеклист `planned-work-checklist.md`.

## О версиях

Точная древняя история версий в репозитории не зафиксирована в одном источнике, поэтому здесь сознательно описаны только актуальное состояние и ближайшие заметные изменения без реконструкции неподтверждённой хронологии.
